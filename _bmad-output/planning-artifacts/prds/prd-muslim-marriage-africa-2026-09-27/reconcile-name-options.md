## 2. What the input actually says

### 2.1 Status and method

- Product name is **TBD**. File is brainstorm input, not a decision.
- Domain evidence is Verisign RDAP on **2026-09-27 ~21:10 ET** (`rdap.verisign.com` `.com` / `.net`). HTTP **404 = free at check time**; HTTP **200 = taken**.
- Caveats the input treats as binding: point-in-time only; a “free” name can be registered by anyone at any moment; **premium / reserved-name pricing not checked**; **trademark conflicts not checked**; nothing registered or bought.

### 2.2 Evaluation frame (qualitative)

- **Themes:** marriage / union / nikah / covenant / tranquillity / trust / path.
- **Criteria:** short; pronounceable for francophone West Africans; respectful (no casual-dating tone); works as a brand in French.
- **Language caveat:** Arabic glosses are standard Qur’anic/hadith vocabulary. **Dioula (Jula) and Mooré glosses are best-effort and must be validated by native speakers in Burkina Faso** before any decision.

### 2.3 Recommended shortlist (3)

1. **Nisfuddin** — “half of the religion” (hadith: marriage completes half of one’s deen). Pan-Muslim / pan-African; clearly marriage, not dating; French-sayable as “nisf-ou-dine.” `.com` + `.net` free at check. **Risk:** spelling. Input advises buying the **`nisfdin`** variant too (also free).
2. **Nikahsira** — Arabic *nikah* + Jula *sira* (road/path) = “the path to nikah.” Rooted in the Burkina / Mali / Côte d’Ivoire Jula belt (launch zone) while still readable for any Muslim. Input reads it as a **journey** (request → wali → nikah), which it says fits the product. `.com` + `.net` free. **Risk:** Jula meaning needs native-speaker confirmation.
3. **Sakinaa** — *sakina* (tranquillity, Ar-Rum 30:21). Input calls it soft, feminine-friendly, trust-evoking — “a good fit for a sister-safety-first brand.” Double “a” is forced because `sakina.com` / `.net` are taken. Alternate named in the same breath: **Mithaqun**.

### 2.4 Alternates / wildcards

- **Mithaqun** — *mīthāq* / “solemn covenant”; Qur’an 4:21 *mīthāqan ghalīẓā*. `.com` + `.net` free. Positioned as Sakinaa alternate, not a fourth shortlist seat.
- **Nonglem** — Mooré “love / affection.” Local-language wildcard to test with Burkina users. `.com` + `.net` free.
- **Dannaya** — Jula/Bambara “trust.” Wildcard, **`.net` only** (`.com` taken). Input does not put it on the recommended three.

### 2.5 Next steps the input marks undone

Trademark (OAPI, covering Burkina Faso and 16 other states, plus WIPO); native-speaker validation for Mooré / Dioula; social-handle check; **user test with 10–20 sisters / brothers / walis in Ouagadougou and Bobo-Dioulasso**. No domain registered or bought.

### 2.6 Broader pool (not shortlisted)

Strongest-28 table plus 65-name RDAP appendix. Notable rejected-with-rationale rows the PRD never absorbed as *guardrails*:

- **Barkawende** — free, but “putting God’s name into a commercial brand may be seen as disrespectful.”
- **Moitiedeen** — free, but “too close to Farata’s ‘Ta moitié’ tagline.”

## 4. Gaps

Qualitative material the input states and the PRD/addendum silently drop or thin. None of these are stance contradictions. They are the drops Finalize should surface before polish.

### G1. Naming evaluation criteria never locked

Input criteria (short; francophone-West-African pronounceable; respectful / no casual-dating tone; works as a French brand) and themes (marriage / union / nikah / covenant / tranquillity / trust / path) do not appear as decision constraints in `prd.md` or `addendum.md`. The PRD carries a list of strings. It does not carry the **rubric** that produced the list. Downstream name work can re-open “what good looks like” as if the brainstorm never said.

### G2. Brand-feel notes on the shortlist dropped

The FR structure kept etymology and dropped voice:

- **Nisfuddin:** French mouth-shape “nisf-ou-dine”; “clearly about marriage and not dating”; spelling risk as a first-class hazard.
- **Nikahsira:** product-fit metaphor — a **path / journey** (request → wali → nikah) matching the launch-zone Jula belt.
- **Sakinaa:** “soft, feminine-friendly and trust-evoking,” fitted to a **sister-safety-first** brand.

Those tones are exactly the class of qualitative idea the reconcile step exists to catch. They are not in Open Questions, not in the Glossary, and not in addendum §6 beyond a one-line meaning.

### G3. Domain evidence caveats compressed

Input is explicit that RDAP “free” is not ownership, that **premium / reserved-name pricing was not checked**, and that a free name can disappear at any moment. Addendum keeps the timestamp and “not a purchase.” It drops the 404/200 method and the premium/reserved caveat. Combined with the input’s advice to buy **`nisfdin` alongside Nisfuddin**, a later reader can treat “both free” as a cleared domain plan. It is not.

### G4. Rejected-name guardrails never captured

Two non-shortlist rows state constraints that should survive even if the names die:

- Do not put **God’s name** into a commercial brand (Barkawende warning).
- Do not echo Farata’s **“Ta moitié”** tagline (Moitiedeen warning).

Neither guardrail is in the PRD name stance, the copy-vocabulary lock, or Open Questions. A later naming pass can rediscover “Moitié deen” and think it is original.
